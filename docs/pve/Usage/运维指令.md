
# 运维指令

***最重要的是避免发生特殊意外：在修改或配置某一个虚拟机或者lxc容器的时候，记得先把自启动关掉，这样出事了可以通过重启的方式以自动关闭设置错误的虚拟机，不至于Pve Web失联！！***


## 强制停止一个无法停止的虚拟机
将101换成你自己虚拟机的VM ID
```bash
ps -ef|grep "/usr/bin/kvm -id 101"|grep -v grep
```
然后会输出一堆信息，第二项就是虚拟机的进程id，这里示例的id是20582.
![[1.png]]

然后强制杀死进程。
```
kill <进程id>
```

## 查看当前所有在运行的虚拟机

```php
pvesh get /cluster/resources
```

## 停止一个lxc容器
```php
lxc-stop -n <编号>
```

